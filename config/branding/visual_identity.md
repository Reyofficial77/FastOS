# FastOS Visual Identity Specification

## Color Palette
- **Primary Accent**: `#007AFF` (Modern Blue)
- **Gradient**: `#007AFF` $\rightarrow$ `#00C6FF`
- **Background (Dark)**: `#1A1A1A`
- **Background (Light)**: `#F5F5F7`
- **Text (Dark)**: `#FFFFFF`
- **Text (Light)**: `#1D1D1F`

## Typography
- **Primary Font**: Inter (San-Serif)
- **Weights**: Regular, Medium, Bold

## Visual Style
- **Window Corners**: 8px radius
- **Borders**: Minimal, 1px subtle grey
- **Shadows**: Soft, diffused depth shadows

## Branding Assets
- **Logo**: FastOS-Logo.png (Minimalist, Blue accent)
- **Wallpaper**: FastOS-Swift-Wallpaper.jpg (Abstract gradients)
- **Icons**: Custom SVG set based on a unified grid
